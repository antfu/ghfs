# GHFS0500: Missing Vercel AI Gateway API key

Code: `GHFS0500`
Level: error

## What this error means

A model-assisted command (`ghfs label`, or "Suggest labels" in the UI) needs a Vercel AI Gateway key to reach the decision model and the context agent, and none was found.

## Why this happens

- `AI_GATEWAY_API_KEY` is not set in the environment or `.env`
- `ai.apiKey` is not set in `ghfs.config.ts`

## How to fix it

```bash
export AI_GATEWAY_API_KEY=vck_xxx
ghfs label
```

Or in `ghfs.config.ts`:

```ts
export default defineConfig({
  ai: { apiKey: process.env.MY_GATEWAY_KEY },
})
```
