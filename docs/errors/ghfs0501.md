# GHFS0501: No repository labels are known locally

Code: `GHFS0501`
Level: error

## What this error means

`ghfs label` asks the decision model one question per repository label, but the local mirror has no label registry to ask about.

## Why this happens

- `ghfs sync` has never run in this directory, so `.ghfs/repo.json` does not exist
- The repository has no labels

## How to fix it

```bash
ghfs sync
ghfs label
```
